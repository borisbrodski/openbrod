# OpenBrod

The umbrella site for the OpenBrod open-source projects, served at <https://openbrod.org> via GitHub Pages.

- [7-Zip-JBinding](https://github.com/borisbrodski/sevenzipjbinding) — the 7-Zip engine, bound to Java
- [Stunt](https://github.com/borisbrodski/stuntmock) — a mocking framework for JUnit 5 that changes classes in place
- [MIG-Ace](https://github.com/borisbrodski/migace) — provable schema migrations for PostgreSQL & Hibernate

The site is a single static page (`index.html` + `favicon.svg`), no build step.
