Open-source developer tools that have to work.

OpenBrod is the home of a small family of developer tools: a long-standing archive library for Java, a mocking framework for code you can't redesign, a toolkit for building DSLs with Langium, and a migration framework that proves your database schema. Free to use, open to contributions.

// projects

Four tools, one standard

Each project solves a hard, concrete problem in real-world code bases, and is documented, tested and released like a product.

7z

7-Zip-JBinding

mature

The real 7-Zip engine, bound to Java.

Extract and create archives with native 7-Zip performance, in-process through JNI. Streaming, callback-driven I/O, one jar for Windows, Linux and macOS.

  • 20+ formats
  • Java 8+
  • LGPL 2.1
  • Maven Central
Website → GitHub
St

Stunt

new

Mock the code you can't inject into.

A mocking framework for JUnit 5 that changes classes in place: statics, private methods, final classes, objects created with new and JDK types — no redesign for testability.

  • JUnit 5
  • Java 17+
  • Apache 2.0
  • JMockit migration guide
Website → GitHub
Lt

langium-tools

released

The work around the grammar, already built.

A TypeScript library for DSLs built with Langium: one list of lexer, parser and validation issues, generators that only rewrite files whose content changed, and snapshot tests for whole trees of generated files.

  • TypeScript
  • Langium 4.4
  • MIT
  • npm
Website → GitHub
MA

MIG-Ace

in development

Schema migrations you can prove.

A migration framework for PostgreSQL and Hibernate that migrates a database with real data and proves the result matches the schema your application expects.

  • PostgreSQL
  • Hibernate
  • Kotlin
  • Gradle

// principles

How we build

Open source doesn't mean unfinished. Every OpenBrod project follows the same rules.

01Real problems

Tools come out of long-running production projects, not from a whiteboard.

02Explicit over magic

Clear behaviour, readable failures, and no surprises for the people who maintain the code.

03Tested and documented

Extensive test suites, CI on every change, and documentation written as a guide.

04Open by default

Open-source licenses, public issue trackers, releases on Maven Central and npm.

Why “OpenBrod”? In Slavic languages, brod means a ford — the shallow place where you can safely cross a river. That's what these tools are for: getting your project safely across the hard parts, one stepping stone at a time.

Contributions welcome

Found a bug, missing a feature, or want to help? Every project has a public issue tracker, and pull requests are reviewed with care.
